### Library - The Odin Project

[To the Website!](https://simon-wdev.github.io/library/)

**Features**
* open a Modal to add books to your library
* every book has a title, author, pages, toggle for read-status and a info for the book
* every book hast it's own random CryptoUID
* MyLib is completely written in Javascript classes
* Remove books from your Library

**Tech:** Javascript (Vanilla), HTML/CSS

The goal was to learn the usage of `object constructors` and later refactor it to `javascript classes` by creating a new branch in git.
